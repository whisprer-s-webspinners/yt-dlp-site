# wofl-dlp

A local web UI for `yt-dlp` that runs downloads on **your own machine** via a localhost companion agent.

The browser gives you a neat page for:

- pasting a URL;
- probing available audio/video formats;
- choosing audio output: WAV, MP3, M4A, FLAC, OPUS;
- choosing video output: MP4, WEBM, MKV, AVI;
- detecting URL timecodes such as `?t=1m23s` and optionally clipping a five-minute section;
- downloading the final file through the browser's normal save/download flow;
- automatic temp cleanup after the browser has fetched the finished file.

Use only with media you own, created, or are otherwise permitted to download. This project deliberately avoids batch/playlist automation and cloud proxying.

## Why this is a localhost app instead of pure browser code

A normal browser page cannot safely run native Python/yt-dlp/ffmpeg binaries or freely write executable temp files. This project therefore serves a browser UI from `127.0.0.1`, and a tiny local Python agent does the native work.

That means the remote media site sees requests from your own machine, not a VPS. The server-side role is reduced to zero unless you choose to host the static project docs elsewhere.

## Install and run

### Windows

Open PowerShell in this folder and run:

```powershell
Set-ExecutionPolicy -Scope Process Bypass -Force
.\run_windows.ps1
```

The script creates `.venv`, installs/updates dependencies, then opens:

```text
http://127.0.0.1:8765/
```

### Linux/macOS

```bash
./run_linux_macos.sh
```

Or manually:

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install --upgrade -r requirements.txt
python -m app.main
```


### YouTube URL repair

The agent repairs common pasted URL mistakes before yt-dlp sees them. For example:

```text
https://youtu.be/watch?v=GVsUOuSjvcg?t=1m23s
```

is normalized to:

```text
https://www.youtube.com/watch?v=GVsUOuSjvcg&t=1m23s
```

This avoids yt-dlp falling back to the generic extractor for malformed YouTube links.

## Cookies

If you need authenticated personal access, export cookies to a local `cookies.txt` file and paste that local path into the Settings panel.

Cookies are never uploaded anywhere by this app. They are read only by the local agent and passed to yt-dlp as `--cookies <path>`.

## ffmpeg

The app uses `imageio-ffmpeg`, which supplies a local ffmpeg binary inside the Python environment. You do not need a system-wide ffmpeg install.

## JavaScript challenge runtimes / EJS

Some sites or formats may require a JavaScript runtime such as Deno, Node, Bun, QuickJS, or QuickJS-NG. The app auto-detects these on `PATH` and passes one to yt-dlp if found.

The Settings panel also has an optional toggle for:

```text
--remote-components ejs:github
```

Leave it off unless yt-dlp warns that you need it. Remote component fetching allows yt-dlp to download helper scripts from GitHub.

## Security model

- The HTTP server binds only to `127.0.0.1:8765`.
- Mutating API requests require a random local token stored in the user config directory.
- POST/PUT requests reject non-local browser origins.
- URLs are restricted to `http://` and `https://`.
- Output files are written to the app cache jobs directory only.
- A single job is allowed at a time to avoid accidental bulk activity.
- Finished temp job folders are deleted after the browser downloads the file.

## Generated yt-dlp behavior

Audio WAV smart-best example generated by the app resembles:

```bash
python -m yt_dlp --ffmpeg-location <bundled-ffmpeg> --no-playlist --newline \
  --paths home:<job-dir> -o "%(title).200B - [%(id)s].%(ext)s" \
  -f "bestaudio[ext=webm]/bestaudio/best" \
  --extract-audio --audio-format wav --audio-quality 0 \
  --postprocessor-args "ffmpeg:-c:a pcm_s24le -ar 48000 -ac 2" \
  --ppa "ffmpeg:-vn -sn" \
  "https://example.invalid/watch?v=..."
```

If a timestamp is detected and clipping is enabled, the app adds:

```bash
--download-sections "*HH:MM:SS-HH:MM:SS" --force-keyframes-at-cuts
```

## Troubleshooting

### Probe works but download fails

Open the job log panel. If yt-dlp says a JavaScript runtime is missing, install one of Deno, Node, Bun, QuickJS, or QuickJS-NG and restart the app.

### Browser does not show a save prompt

Most browsers automatically save to Downloads. Check your browser's download settings and enable “Ask where to save each file before downloading” if you want a prompt every time.

### Cookies file errors

Make sure the path is a real Netscape-format cookies file readable by your user account.

### Need a clean reset

Delete the app config/cache directories shown by the UI/system panel, or remove `.venv` and rerun the launcher to reinstall Python dependencies.
